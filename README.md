# CMPM 121 D1 Project - TikTak Likes Farm

A TikTok-themed incremental clicker game where players generate "likes" by clicking a heart button and purchasing upgrades to automate production and dont worry TikTak is on purpose.

## UI Improvements Inspired by Peer Projects

This project incorporates design improvements inspired by classmates' submissions:

### 1. Centered Layout & Borderless Button Design

**Inspired by:** [Banana Game - https://github.com/mrpoopers/D1rich/tree/main/src]

- Implemented centered flexbox layout for all game elements
- Removed borders from the main click button for a cleaner, more modern look
- Added smooth hover and click animations for better user feedback

### 2. Dynamic Upgrade Button States

**Inspired by:** [Bryce Han's Monke Game - https://github.com/BHan2002/cmpm-121-f25-d1]

- Upgrade buttons dynamically enable/disable based on player's current like count
- Visual feedback clearly shows when upgrades become affordable
- Disabled state uses reduced opacity and "not-allowed" cursor
